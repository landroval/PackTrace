I use the source/publisher mapping documented at https://google.github.io/osv.dev/data/ and its redistribution description at https://google.github.io/osv.dev/data/new#data-licensing. Unknown publisher/license profiles block activation; a namespace claim is not a publisher signature. OSV's software license is not a blanket license for the aggregated data.

OSV enriches the records. PackTrace retains their received original bytes, including notices and credits, and builds local indexes. License texts and publisher/source attribution accompany the generation's portable object graph. No publisher endorsement, organizational approval or general legal-compliance guarantee is asserted. No advisory dataset is embedded here.

pnpm12.18.0 pair. This does not renew the earlier exhausted32-call campaign or
permit publication, merge, release, native CI, installed-binary replacement,
project scans, automatic tool acquisition or installer execution.

use. Reuse the rootless private PID/network namespace, readonly tools, scripts-off
owned loopback fixtures, positive/negative isolation controls, bounded output and
confirmed direct-child/group cleanup. Persist reservations before every namespace

flags: no obsolete manager-version flag, no packageManager self-resolution in the

produces a capture with passing controls, run hoisted copy, distinct-peer copy and
hardlink-requested cases. Inspect actual link multiplicity; a backend label is not
proof of hardlinks. An unused allowance is not a successful case.

stable12.x hints if the actual bounded parser/collector/parent/CLI cases justify
